githubでWebページをつくる方法

手順

本アカウント名 mmsaito，webサイトのレポジトリ名 webSkeltonで例を示す．
  • https://github.com/mmsaito?tab=repositories に行き，Newをクリックして新しいレポジトリwebSkeltonをつくる．
  • ローカルで適当なフォルダに index.htmlをつくり，その後 
    
git init (最初だけ)
git remote add origin https://mmsaito.github.io/webSkelton.git (最初だけ)
git add index.html
git commit
git push origin master
  • Setting-PagesについてBuild and deploymentで masterブランチをWeb作成用のブランチとして選ぶ．デフォルトではNoneになっており，ブラウザでアクセスすると Not foundになる．
  • ブラウザで https://mmsaito.github.io/webSkelton/ を開く．
